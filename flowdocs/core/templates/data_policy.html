Data Policy

Last updated: 24 July 2026

1. Data Classification

Data within the Sahakar AI platform is classified into the following categories:

  • Public Data: Government circulars, acts, and regulations that are publicly available and indexed for search.
  • Operational Data: User accounts, search logs (transient), and system configuration.
  • Derived Data: FAISS indexes, embeddings, and chunked document representations generated from uploaded PDFs.
  • Artifact Data: Immutable backup generations stored in the S3-compatible artifact vault.

3. Backup Policy

The platform maintains a multi-generational backup system through its artifact vault:

  • Generations: Each backup creates an immutable generation containing PDF files, database state, FAISS indexes, and metadata manifests.
  • Storage: Artifacts are stored in an S3-compatible object store (RustFS), isolated from the application network.
  • Retention: A configurable number of recent generations is retained. Older generations are purged automatically.
  • Validation: Each generation is validated for integrity (checksum verification, PDF count, index coherence) before being marked as available for restore.
  • Promotion: A validated generation can be promoted to active, superseding the current active dataset.
  • Rollback: Any non-active generation can be restored to staging and promoted if needed.

4. S3 Artifact Vault

The artifact vault is an S3-compatible object storage system (RustFS) that stores immutable snapshots of the platform's data. Key properties:

  • Isolated from the application network — vault operations require explicit, authenticated commands.
  • Each generation includes: SQLite database dump, PDF file archive, FAISS index files, and a signed manifest.
  • Manifests include generation ID, creation timestamp, PDF count, checksums, and source environment identity.
  • Vault access is restricted to superadmin-level maintenance operations.

5. Data Deletion Procedures

Data deletion follows a structured lifecycle:

  1. Deprecation: A PDF is marked as deprecated — it is hidden from search results but preserved in the database and vault generations.
  2. Archival: A PDF is marked as archived — it is hidden from search and dashboard lists but retained in the database.
  3. Deletion: A PDF is removed from storage and database. Prior vault generations that include the file are not retroactively purged.
  4. Account Deletion: A user account may be deleted only after all owned documents and folders have been transferred or removed.
  5. Generation Purge: Expired artifact generations are purged from the vault, removing all associated files and metadata.

6. Data Subject Rights

Under the DPDA 2023, data subjects (users) have the right to:

  • Request confirmation of whether their personal data is being processed.
  • Access their personal data held by the platform.
  • Request correction of inaccurate or incomplete personal data.
  • Request erasure of their personal data, subject to legal retention requirements.
  • File a grievance with the Grievance Officer at grievance@ai-sahakar.net.
